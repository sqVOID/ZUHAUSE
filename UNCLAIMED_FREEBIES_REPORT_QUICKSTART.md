# Unclaimed Freebies Report - Quick Start Guide

## How to View Unclaimed Freebies Breakdown

### Step 1: Open Daily Sales Report
```
Navigate to: Reports → Daily Sales Report
URL: http://localhost/MOTOGAM/report.php
```

### Step 2: Select Date Range
- **Single Day**: Select same date for both "From" and "To"
- **Date Range**: Select different dates

### Step 3: Select Branch
- **User**: Automatically your branch
- **Sub-admin/Super-admin**: Choose from dropdown

### Step 4: Click "Search"
- Daily Sales Table appears (existing feature)
- Sales Breakdown appears (existing feature)
- **Unclaimed Freebies Breakdown appears** (NEW! ✨)

### Step 5: Review Breakdown
The new section shows:

1. **Summary Statistics**
   - Total records
   - Unclaimed count (in red)
   - Claimed count (in green)

2. **By Branch**
   - Unclaimed (U), Claimed (C), Total (T) per branch

3. **By Item**
   - Item code and description
   - Unclaimed and claimed quantities

4. **Detailed Table**
   - Complete listing with all details

### Step 6: Print (Optional)
Click "Print" button → All sections included in PDF

## What Each Section Tells You

### Summary Section
```
TOTAL RECORDS: 15          ← Total freebie entries
UNCLAIMED: 10 (12 items)   ← Red text: Still pending
CLAIMED: 5 (7 items)       ← Green text: Already claimed
```

**Interpretation**:
- **High unclaimed**: Customers haven't picked up items yet
- **High claimed**: Good claim rate

### By Branch Section
```
MAIN: U: 5 | C: 3 | T: 8
```

**Interpretation**:
- MAIN branch has 8 total freebies
- 5 are unclaimed
- 3 are claimed
- Claim rate: 37.5% (3/8)

### By Item Section
```
HELMET-01
  Full Face Helmet
  Unclaimed: 4 (5 qty) | Claimed: 2 (3 qty)
```

**Interpretation**:
- 4 invoices have unclaimed helmets
- Total 5 helmets unclaimed
- 2 invoices already claimed
- Total 3 helmets claimed
- Popular item: 6 invoices total

### Detailed Table
Shows every single freebie entry with:
- **Invoice**: Which sale it's from
- **Item Code**: Product code
- **Description**: Product name
- **Qty**: Quantity
- **Status**: UNCLAIMED (red) or CLAIMED (green)
- **Customer**: Who to contact
- **Branch**: Which location
- **Encoder**: Who created entry
- **Date**: When it was entered

## Common Questions

### Q: I don't see the Unclaimed Freebies section
**A**: This means there are no unclaimed or claimed freebies for the selected date range and branch.

### Q: Can I export this data?
**A**: Yes! Click "Print" and the unclaimed freebies breakdown will be included in the PDF.

### Q: How often should I check this?
**A**: Recommended:
- **Daily**: For high-volume branches
- **Weekly**: For regular monitoring
- **Monthly**: For trend analysis

### Q: What should I do with long-standing unclaimed items?
**A**: 
1. Contact the customer (phone/email from detailed table)
2. Check if item is still available
3. Set reminder for follow-up
4. Update item status when claimed

### Q: Can I see only unclaimed items?
**A**: Currently shows both unclaimed and claimed. The color coding (red) makes unclaimed items easy to spot.

### Q: Does this affect the existing Daily Sales Report?
**A**: No! It's an addition. All existing features work exactly the same.

## Troubleshooting

### Issue: "Loading..." never finishes
**Solution**: 
- Check internet connection
- Refresh page
- Contact IT if persists

### Issue: Wrong data displayed
**Solution**:
- Verify date range is correct
- Verify branch selection
- Click Search again

### Issue: Can't print breakdown
**Solution**:
- Ensure data is loaded first
- Try Print Preview
- Check printer settings

### Issue: Numbers don't match expected
**Solution**:
- Verify date range includes all expected dates
- Check if filtering by specific branch
- Confirm data was entered in system
