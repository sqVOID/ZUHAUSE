HOW TO USE
───────────────────────────────────────────────────────────────────

STEP 1: Configure Booklet (Optional)
→ Go to: Store Registration → Booklet Number Registration
→ Click: Add Booklet Number
→ Fill:
  - Branch: [Select your branch]
  - Page Type: Stock Transfer
  - Format: Numeric / Date+Suffix / Custom
  - Prefix: [Optional, e.g., "ST-"]
  - Current Number: [Starting number]
  - Suffix: [Optional]
→ Click: Add

STEP 2: Create Stock Transfer
→ Go to: Stock Transfer page
→ ST Number field will auto-display next number
→ Fill transfer details and items
→ Click Save
→ ST number will be generated using booklet format

───────────────────────────────────────────────────────────────────
EXAMPLES
───────────────────────────────────────────────────────────────────

WITH BOOKLET CONFIGURED:
  Format: Numeric, Prefix="ST-", Current="0001", Suffix=""
  Result: ST-0001 → ST-0002 → ST-0003

  Format: Numeric, Prefix="", Current="0001-092", Suffix="-ST"
  Result: 0001-092-ST → 0002-092-ST → 0003-092-ST

  Format: Date+Suffix, Current="07-06-2026", Suffix="-ST"
  Result: 07-06-2026-ST (manually update date daily)

WITHOUT BOOKLET (Fallback):
  Format: ST-YYYYMMDD-###
  Result: ST-20260706-001 → ST-20260706-002 → ST-20260706-003
