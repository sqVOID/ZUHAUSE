INSTALLATION STEPS:

Step 1: Create Database Table
═══════════════════════════════════════════════════════════════════════════════
Open your browser and navigate to:
→ http://localhost/MOTOGAM/setup_booklet_numbers.php

This will create the 'booklet_numbers' table in your database.
You should see a success message.

Step 2: Access the Registration Page
═══════════════════════════════════════════════════════════════════════════════
Navigate to the page via:
→ Sidebar: Store Registration → Booklet Number Registration
   OR
→ Direct URL: http://localhost/MOTOGAM/bookletnoreg.php

Step 3: Add Your First Booklet Number
═══════════════════════════════════════════════════════════════════════════════
1. Click "Add Booklet Number" button
2. Select a branch
3. Choose format type:
   • Numeric: For formats like 0003128-092-149
   • Date + Suffix: For formats like 07-06-2026-SD10
   • Custom: For any other format
4. Enter the current number
5. Optionally add prefix/suffix
6. Preview the format
7. Click "Add" to save

Step 4: Test the Integration (Optional)
═══════════════════════════════════════════════════════════════════════════════
Open the test page:
→ http://localhost/MOTOGAM/test_booklet_integration.php

Select a branch and click "Get Next Invoice Number" to test.

INTEGRATION WITH SALES SYSTEM:

To use booklet numbers in your sales entry or invoice system, add this code:

PHP Example:
─────────────────────────────────────────────────────────────────────────────
<?php
include 'get_next_invoice_number.php';

// Get the booklet configuration for current branch
$branch_code = $_SESSION['branch_code']; // or from form
$booklet = getBookletConfig($conn, $branch_code);

if ($booklet) {
    // Generate the full invoice number
    $invoice_number = generateInvoiceNumber($booklet);
    
    // Use it in your sales entry
    echo "Invoice Number: " . $invoice_number;
}
?>

JavaScript/AJAX Example:
─────────────────────────────────────────────────────────────────────────────
fetch('get_next_invoice_number.php', {
    method: 'POST',
    headers: {'Content-Type': 'application/x-www-form-urlencoded'},
    body: 'action=get_invoice_number&branch_code=SD'
})
.then(response => response.json())
.then(data => {
    if (data.success) {
        document.getElementById('invoice_field').value = data.invoice_number;
    }
});

TROUBLESHOOTING:

Problem: Table creation fails
Solution: Check database connection in config.php
         Ensure MySQL is running
         Verify database name is correct

Problem: Menu item not visible
Solution: Check sidebar permissions
         Clear browser cache
         Verify user role has access

Problem: Can't add booklet number
Solution: Ensure branch exists in branches table
         Fill all required fields (marked with *)
         Check for duplicate entries

Problem: Preview not showing
Solution: Check browser console for errors
         Ensure JavaScript is enabled
         Clear cache and reload

• Only ONE booklet number per branch should be Active at a time
• Inactive booklet numbers are kept for historical reference
• You can manually update the current number at any time
• Auto-increment is available for numeric formats
• Date formats should be updated manually per day
