HOW TO USE
───────────────────────────────────────────────────────────────────

STEP 1: Configure Booklet (Optional)
→ Go to: Store Registration → Booklet Number Registration
→ Click: Add Booklet Number
→ Fill:
  - Branch: [Select your branch]
  - Page Type: Pre-Order
  - Format: Numeric / Date+Suffix / Custom
  - Prefix: [Optional, e.g., "PRE-"]
  - Current Number: [Starting number]
  - Suffix: [Optional]
→ Click: Add

STEP 2: Create Pre-Order
→ Go to: Pre-Order page
→ Invoice No field will auto-display next number
→ Fill customer and item details
→ Click Payment button
→ Invoice will be generated using booklet format

───────────────────────────────────────────────────────────────────
EXAMPLES
───────────────────────────────────────────────────────────────────

WITH BOOKLET CONFIGURED:
  Format: Numeric, Prefix="PRE-", Current="0001", Suffix="-M"
  Result: PRE-0001-M → PRE-0002-M → PRE-0003-M

  Format: Date+Suffix, Current="07-06-2026", Suffix="-SD"
  Result: 07-06-2026-SD (manually update date daily)

WITHOUT BOOKLET (Fallback):
  Format: PRE-YYYYMMDD-####
  Result: PRE-20260706-0001 → PRE-20260706-0002 → PRE-20260706-0003
