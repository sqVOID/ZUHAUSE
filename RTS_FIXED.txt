DATABASE TABLES STRUCTURE:
--------------------------

1. return_to_supplier (Main records)
   - id, rts_number, rts_date, reference_number
   - branch_from, branch_name, delivery_to, remarks
   - created_by, created_at, updated_at

2. return_to_supplier_items (Items)
   - id, rts_id, rts_number
   - item_code, item_description, imei
   - quantity, cost, reason

3. rts_approval_log (Approval workflow)
   - id, rts_id, rts_number, reference_number
   - branch_from, branch_code, delivery_to
   - reason, remarks, total_items
   - created_by, created_at
   - approver, approval_date
   - disapprover, disapproval_date
   - status (Pending/Approved/Disapproved)

BOOKLET NUMBERS TABLE:
----------------------
The booklet_numbers table has these columns:
- id, branch_code, page_type
- booklet_format, current_number
- prefix, suffix, description
- status, created_at, updated_at

NOTE: Does NOT have invoice_number, used_at, used_by columns!

COST CALCULATION:
-----------------
Items costs are fetched from:
1. purchase_order_items.cost (primary)
2. items.srp (fallback if no PO cost)
3. 0 (if neither found)
