HOW IT WORKS:

┌─────────────────────────────────────────────────────────────────────────────┐
│ FRONTEND (salesentry.php)                                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│ 1. Page loads                                                               │
│ 2. JavaScript calls get_next_invoice_number.php with branch_code           │
│ 3. Displays current invoice number in the form                             │
│ 4. If no booklet configured: shows "System Generated"                      │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ BACKEND (save_sales_entry.php)                                              │
├─────────────────────────────────────────────────────────────────────────────┤
│ 1. User completes sale and submits                                         │
│ 2. Script checks for active booklet configuration                          │
│ 3. If booklet exists:                                                       │
│    • Generates invoice using booklet format                                │
│    • Auto-increments if numeric format                                     │
│    • Updates booklet for next invoice                                      │
│ 4. If no booklet:                                                           │
│    • Uses fallback format: YYMMDD-BRANCHCODE-XXXXX                         │
│ 5. Saves invoice number to sales_entry table                               │
└─────────────────────────────────────────────────────────────────────────────┘

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SUPPORTED INVOICE FORMATS:

Format 1: Numeric Sequential
───────────────────────────────────────────────────────────────────────────────
Example: 0003128-092-149
Config:  Format: Numeric, Current: 0003128-092-149
Feature: Auto-increments on each sale
Next:    0003128-092-150

Format 2: Date with Suffix
───────────────────────────────────────────────────────────────────────────────
Example: 07-06-2026-SD10
Config:  Format: Date+Suffix, Current: 07-06-2026, Suffix: SD10
Feature: Manual update required (typically daily)
Next:    07-07-2026-SD10 (after manual update)

Format 3: Prefix + Number
───────────────────────────────────────────────────────────────────────────────
Example: BR001234
Config:  Format: Custom, Prefix: BR, Current: 001234
Feature: Manual update or custom logic
Next:    BR001235 (manual)

Format 4: Full Custom
───────────────────────────────────────────────────────────────────────────────
Example: INV-2026-MNL-00123
Config:  Format: Custom, Prefix: INV-2026-, Current: MNL-00123
Feature: Complete flexibility
Next:    Manual update required

Format 5: Fallback (No Booklet)
───────────────────────────────────────────────────────────────────────────────
Example: 260706-SD-00001
Config:  None (uses old system)
Feature: Auto-increments daily sequence
Next:    260706-SD-00002

SETUP INSTRUCTIONS:

Step 1: Run Database Setup
───────────────────────────────────────────────────────────────────────────────
URL: http://localhost/MOTOGAM/setup_booklet_numbers.php

This creates the booklet_numbers table. Run once only.

Step 2: Configure Booklet Number
───────────────────────────────────────────────────────────────────────────────
1. Navigate: Sidebar → Store Registration → Booklet Number Registration
2. Click "Add Booklet Number"
3. Select your branch
4. Choose format type
5. Enter current number (can be your last invoice number)
6. Add prefix/suffix if needed
7. Click Add

Step 3: Test Integration
───────────────────────────────────────────────────────────────────────────────
1. Open Sales Entry page
2. Verify invoice number shows your booklet format
3. Complete a test sale
4. Check that invoice saved correctly
5. For numeric format: verify next invoice incremented

Step 4: Verify in Database
───────────────────────────────────────────────────────────────────────────────
SELECT invoice_no, branch_code, created_at 
FROM sales_entry 
ORDER BY id DESC LIMIT 5;

TROUBLESHOOTING:

Problem: Invoice shows "System Generated"
Solution: Add booklet configuration for the branch

Problem: Invoice doesn't increment
Solution: Use numeric format for auto-increment, or update manually

Problem: Wrong branch getting wrong format
Solution: Verify branch_code in booklet configuration

Problem: Old format still showing
Solution: Ensure booklet status is Active, refresh page
