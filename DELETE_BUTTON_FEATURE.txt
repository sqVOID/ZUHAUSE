───────────────────────────────────────────────────────────────────
FUNCTIONALITY
───────────────────────────────────────────────────────────────────

1. CONFIRMATION DIALOG
   User clicks Delete → Browser shows:
   "Are you sure you want to delete this booklet number? 
    This action cannot be undone."
   
   Options:
   - OK → Proceeds with deletion
   - Cancel → No action taken

2. DELETION PROCESS
   If confirmed:
   - Sends request: bookletnoreg.php?delete=[ID]
   - PHP executes: DELETE FROM booklet_numbers WHERE id = [ID]
   - Redirects to: bookletnoreg.php?deleted=1
   - Shows success message

3. SUCCESS MESSAGE
   Green alert box displays:
   "✓ Booklet number deleted successfully!"
   
   Message auto-cleans URL (removes ?deleted=1 parameter)

4. ERROR HANDLING
   If deletion fails:
   - Red alert box displays error
   - Database error message shown
   - User can try again

TECHNICAL DETAILS
───────────────────────────────────────────────────────────────────

PHP Handler:
```php
if (isset($_GET['delete'])) {
    $id = $conn->real_escape_string($_GET['delete']);
    $sql = "DELETE FROM booklet_numbers WHERE id = $id";
    
    if ($conn->query($sql) === TRUE) {
        header("Location: bookletnoreg.php?deleted=1");
        exit();
    }
}
```

HTML Button:
```php
echo "<a href='bookletnoreg.php?delete=" . $row['id'] . "' 
         class='btn-delete' 
         onclick='return confirm(\"Are you sure...\")'>
         Delete
      </a>";
```

Success Message:
```php
if (isset($_GET['deleted']) && $_GET['deleted'] == 1) {
    $message = "Booklet number deleted successfully!";
    $messageType = "success";
}
```
